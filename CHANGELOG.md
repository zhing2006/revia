# Changelog

## [0.1.1] - 2026-10-10

- Added a command-line exporter with automatic processing, optional alignment, color and mask settings, and PNG, mask PNG, and PSD output.
- Added draggable split comparison between the composite result and the edited image, with synchronized zoom and pan.
- Fixed images occasionally not fitting the canvas when first opened.
- Fixed different frames of the same animation being treated as identical images.

## [0.1.0] - 2026-10-10

- Initial release of Revia.
